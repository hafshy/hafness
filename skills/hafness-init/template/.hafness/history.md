# History

Every prompt typed in this project, appended by `history.sh` (a prompt hook). Prompts that
run a Hafness command carry its name as a tag. Append only.

Everything you type lands here, and this file is committed. If you paste a secret, delete
that entry and rotate the secret.

**Header grammar** — fixed, linted by `verify.sh`:

    ## YYYY-MM-DD HH:MM · <prompt|`command`>
